# Implementación en C++ – Sistema de Control de Estudiantes

Este directorio contiene la implementación en **C++** del sistema de control de estudiantes y notas, desarrollado aplicando los principios de la **Programación Orientada a Objetos (POO)**.

---

## Archivos incluidos

| Archivo | Descripción |
|---|---|
| `main.cpp` | Código fuente completo: clase `Estudiante` + función `main()` |
| `README.md` | Este archivo de documentación |

---

## Requisitos

- **Compilador:** g++ 9.0 o superior (MinGW, GCC, Clang)
- **Sistema operativo:** Windows
- **Editor recomendado:** Visual Studio Code, Code::Blocks
