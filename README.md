##  Descripción del Proyecto

Este proyecto implementa un **sistema de control de estudiantes y notas** que permite:

- Registrar **mínimo 5 estudiantes**.
- Ingresar **3 notas** por cada estudiante (rango válido: **0 a 10**).
- Calcular automáticamente el **promedio** de cada estudiante.
- Determinar si el estudiante **APRUEBA** (promedio ≥ 7.00) o **REPRUEBA**.
- Mostrar el **listado completo** con cédula, nombre, notas, promedio y estado.
- Contar el total de **aprobados y reprobados**.
- **Validar** que las notas estén dentro del rango permitido.

Todo el sistema está construido aplicando los **4 pilares de la POO**:
**Abstracción**, **Encapsulamiento**, **Herencia** y **Polimorfismo** (con énfasis en los dos primeros).
